# Myzel – notes for Claude

- The app's source is `myzel/src/` (modules: `html/`, `css/`, `js/…`, German UI); the module order is the `@include` lines in `myzel/src/index.html`. `myzel/index.html` is the built output, committed alongside it – never edit it by hand. After editing modules, build with `python3 myzel/build.py myzel/src myzel/index.html` and commit both (`pwa/build.py`, the Pages job and the test builder `mk.sh` refuse a stale `index.html`). Before publishing, also run `python3 myzel/pwa/build.py <scratch>/site` – the Pages job runs it and refuses a CHANGELOG entry with fewer than 2 or more than 6 points (25.10.2026: two releases failed on this). Locate code with `grep -rn name myzel/src`.
- Work continues from `dev/HANDOFF.md` – read it first: current state, binding specs in `dev/klang/`, test setup (`sh dev/setup-tests.sh <scratchpad>`), next stages.
